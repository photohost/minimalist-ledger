日常留白 · 隱私權說明

本網站讓使用者記錄個人收支、預算與儲蓄。主網站由 GitHub Pages 提供，Google 登入與檔案存取使用 Google Identity Services 和 Google Drive API。

取得的 Google 資料與用途

授權時取得帳號識別碼與電子郵件，用來顯示目前帳號、區分帳目及裝置暫存。網站申請 drive.file 權限，只讀寫使用者允許本應用程式存取的檔案；網站實作只讀寫自己建立的帳目與資料夾，不掃描其他個人檔案。

帳目保存

使用 Drive 時，帳目版本保存在你的「我的雲端硬碟／日常留白記帳」資料夾。檔案包含輸入的金額、分類、說明與預算，不會自動公開或分享。版本保留是為避免同步時遺失資料；使用者可以透過 Drive 管理或刪除檔案。

未登入的帳目保存在瀏覽器本機。登入後帳目依帳號分開保存在此瀏覽器。離線或關閉網頁時，待同步資料仍留在此瀏覽器。匯出備份由使用者保存；請自行保管個人財務資料。

授權與登出

Google 密碼不會傳給本網站。存取權杖只放在頁面記憶體，不寫入帳目或備份；一般模式在重新整理或授權到期後需重新連線。若網站啟用長效登入，登入服務會用加密且無法由頁面讀取的 Cookie 保留最多 30 天的授權，並在使用網站時向 Google 續期。登出會結束本站的 Google 連線。本機帳目需登入同一帳號才能透過本站再次開啟。若在共用裝置使用，請先確認帳目已同步，再清除瀏覽器中這個網站的資料。可至 Google 帳號連線管理撤銷授權。

資料使用

本網站程式不將 Google 使用者資料出售、用於廣告或提供給其他使用者。資料只用於使用者要求的記帳、同步與備份功能。Google API 資料的使用與傳送遵守 Google API Services User Data Policy，包含 Limited Use 要求。

其他服務

使用 GitHub 儲存時，帳目依使用者設定上傳私人 GitHub 倉庫。Google、GitHub 與字體提供者仍依各自政策處理服務請求。

聯絡與版本

網站原始碼與問題回報：GitHub 專案。回報時請勿貼出帳目、OAuth 權杖或密碼。
