每日記帳

點選早餐、午餐、晚餐、其他，直接輸入實際金額，按儲存即記帳。前後翻頁可補記，午夜 00:00 會自動換到新的一天。

日期依裝置時間；休眠或切到背景後，回到頁面會檢查日期。昨日帳目會保留，尚未完成的表單仍存回原本那一天。

看懂金額

卡片下方顯示當日花費、當日三餐額度使用率，以及本期剩餘三餐與總預算。當日額度按本期天數平均分配；每期為 5 日至次月 4 日。非今天為灰色稿紙，超過當日三餐或總額度則優先顯示紅色，並標示超支。

計算方式與資料保存

剩餘總預算先預留固定支出與儲蓄，再扣三餐、其他實際花費；固定付款不再扣第二次。固定預留取分類預算與明細各自預算／實際較大值總和的較大者。總可支用額取三餐＋其他預算與收入扣預留後的較小者；未知的一側暫用已知的一側，均未知則留空。預計可存＝收入－預估總支出。分類預估取分類預算與明細預估較大者，避免重複加總。明細未完成取預算與實際較大者，完成則取實際。空白代表未知，總計暫以 0 加總，並提醒尚未完整。

房租與訂閱只在設定管理，不列入每日卡片或月曆花費。信用卡費若包含已記錄消費，請只記未記過的款項，避免重複計算。

連線私人 GitHub 資料倉庫後，每次儲存會先留本機副本，再自動上傳 ledger.json。只有顯示「已同步至 GitHub」才代表上傳完成。換裝置請重新連線並選擇「下載 GitHub 帳目」。未連線、離線或權限失效時僅存本機，請保留備份並重試。

權杖只留在本頁記憶體，重新整理或關閉後需重新輸入。私人倉庫的歷史版本也包含舊帳目，請勿改為公開。GitHub Pages 只提供網頁；實際同步由網頁連接 GitHub API 完成。

Google 登入可在設定中啟用；帳目存於 Google Drive，與 GitHub 擇一同步。每次儲存先留本機。重新開啟後登入同一帳號，即可接續未同步的帳目。詳見 Google 設定指南。
